# Welcome 

*Começando*
Entrar na pasta de gestao-financeira

cd gestao-financeira

1. Baixar as dependências
o primeiro comando no terminal, após pressionar Ctrl + J será :
  
   npm install

Outras dependências para instalar e comandos para rodar no terminal, serão:

npx expo install @react-native-picker/picker
npx expo install @react-native-async-storage/async-storage
npx expo install @react-native-community/datetimepicker

2. Teste o app

   npx expo start -c
Após esse comando no terminal, ou aperte a tecla W ou a ou leia o QR code com o Celular.
Outro comando que pode ser testado é npx run android.
